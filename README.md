# darkmoon.pt

The website for [darkmoon](https://darkmoon.pt), a RAW photo editor for
Windows, macOS and Linux.

**Nothing here is edited by hand.** These pages are written and reviewed
in the application's own repository and copied here by
`docs/publish_site.sh`; `privacy.html` and `terms.html` are generated
from the same `PRIVACY.md` and `EULA.md` that the application ships and
displays in its Credits screen, so the text on the web and the text in
the product cannot drift apart.

This repository exists because the application's repository is private,
and GitHub Pages will not serve a private repository on the free plan.
It holds the served site and no source, in the same way
[darkmoon-models](https://github.com/vinioliveiras/darkmoon-models)
holds the model packs that cannot travel inside a release.
